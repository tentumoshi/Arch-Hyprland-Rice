# Hyprland Rice

My first Arch Linux Hyprland desktop customization and configuration built around a dark, minimal visual style with transparency, blur, and muted teal accents.

## Theme

**Charcoal + Silver + Muted Teal**

- Background: `#0A0A0B`
- Surface: `#111214`
- Foreground: `#E8EAED`
- Accent: `#72C7B8`

## Included Configurations

- **Hyprland** — window management, animations, keybindings, opacity, and window rules
- **Hyprlock** — customized lock screen with media information
- **Hypridle** — automatic locking before suspend
- **Waybar** — status bar and system modules
- **Rofi** — application launcher
- **Ghostty** — terminal configuration
- **Cava** — audio visualizer
- **Spicetify** — Spotify customization
- **Visual Studio Code** — editor appearance and transparency
